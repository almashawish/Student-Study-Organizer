# Student Study Organizer

## Project Overview
Student Study Organizer is a simple Python command-line program. It helps students keep a list of school subjects and study tasks. Students can also mark tasks as completed and check their progress.

## Problem Statement
Students sometimes forget their study tasks or find it difficult to keep track of what they have finished. This program provides a simple way to organize subjects and tasks in one place while it is running.

## Features
1. Add a new subject.
2. View all subjects.
3. Add a study task for a subject.
4. View all study tasks and their status.
5. Mark a task as completed.
6. Show the number of completed and pending tasks.
7. Exit the program.

Each task has a task name, a subject name, and a status (`Pending` or `Completed`).

## Technologies Used
- Python 3
- Command-line interface
- No external libraries

## How to Run the Program
1. Install Python 3 if it is not installed.
2. Open a terminal in the `Student-Study-Organizer` folder.
3. Run:

   ```bash
   python main.py
   ```

   On some computers, use `python3 main.py` instead.
4. Enter a menu number from 1 to 7 and follow the instructions.

**Note:** This beginner project does not save data to files. Subjects and tasks are cleared when the program closes.
